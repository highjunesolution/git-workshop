สรุปภาพจำของ Workshop 01

git init 
= เปิดระบบ Git ในโฟล์เดอร์นี้

git status
= เช็กว่าไฟล์ตอนนี้อยู่สถานะไหน

git add 
= เตรียมไฟล์เข้า commit

git commit
= บันทึกประวัติ

git log
= ดูประวัติ

git diff
= ดูสิ่งที่แก้แล้ว แต่ยังไม่ได้ git add

git diff --staged
= ดูสิ่งที่ git add แล้ว และกำลังจะ commit

ถ้าดู diff แล้วรู้สึกว่า “ไม่เอาดีกว่า” ใช้:
git restore README.md

สรุปจำง่าย

git status
= บอกว่าไฟล์ไหนเปลี่ยน

git diff
= บอกว่าเปลี่ยนอะไร ก่อน git add

git diff --staged
= บอกว่าเปลี่ยนอะไร หลัง git add

git restore <file>
= ยกเลิกการแก้ไขไฟล์ กลับไปเหมือน commit ล่าสุด

ภาพรวมของ git ตอนนี้

Working Directory
ไฟล์ที่เราเพิ่งแก้
        ↓ git diff ดูตรงนี้
Staging Area
ไฟล์ที่ git add แล้ว
        ↓ git diff --staged ดูตรงนี้
Repository
ไฟล์ที่ commit แล้ว
